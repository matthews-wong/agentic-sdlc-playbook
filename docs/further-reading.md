# Further Reading

A short, curated path beyond this playbook. Full citations live in [references.md](./references.md); this page is about *where to go next* and why.

## Start here (foundational)

- **Anthropic — [Building Effective Agents](https://www.anthropic.com/engineering/building-effective-agents)** — the source of the five orchestration workflows and the workflow-vs-agent distinction. Read it first; the rest of this playbook builds on it.

## Going deeper on patterns

- **[Agentic design pattern catalogs (2026)](https://www.augmentcode.com/guides/agentic-design-patterns)** — broader pattern taxonomies (reflection, tool use, planning, ReAct, multi-agent) if you want more than the essentials here.
- **[Vellum — emerging architectures](https://www.vellum.ai/blog/agentic-workflows-emerging-architectures-and-design-patterns)** — how patterns are being combined in production systems.

## The SDLC angle

- **[CodeRabbit — agentic SDLC guide](https://www.coderabbit.ai/guides/agentic-sdlc)** and **[Augment Code — what changes when agents run development](https://www.augmentcode.com/guides/agentic-sdlc)** — practitioner framing of the lifecycle.
- **[Forrester — from code assistants to orchestrated SDLC agents](https://www.forrester.com/blogs/agentic-software-development-takes-the-lead-from-code-assistants-to-orchestrated-sdlc-agents/)** — the market/organizational view and where this is heading.
- **[Microsoft — an AI-led SDLC on Azure + GitHub](https://techcommunity.microsoft.com/blog/appsonazureblog/an-ai-led-sdlc-building-an-end-to-end-agentic-software-development-lifecycle-wit/4491896)** — a concrete end-to-end reference.

## Choosing tools

- **[2026 agent framework comparisons](https://qubittool.com/blog/ai-agent-framework-comparison-2026)** — for when you've decided you actually need a framework (see [tooling-landscape.md](./tooling-landscape.md) first).
- **Anthropic's own docs** — for canonical Claude Agent SDK / Claude API usage; prefer primary docs over third-party summaries for anything you'll build on.

## How to read all this

Hold everything against one test from the playbook: **does it help you use the least autonomy the task needs, gated by consequence, measured by outcomes?** Sources that push more autonomy without observability or verification are describing the [anti-patterns](./anti-patterns.md), not the goal.
